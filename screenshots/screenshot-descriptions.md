- **Format**: PNG or JPEG
- **Quantity**: 1-5 screenshots (we'll create 5)

## How to Create Screenshots

### Method 1: Using the HTML Generator
1. Open `generate_screenshots.html` in Chrome
2. Set browser to 1280x800 resolution
3. Use developer tools to capture screenshots
4. Save as PNG files

### Method 2: Using the Actual Extension
1. Load the extension in Chrome
2. Open the extension window
3. Set up different scenarios for each screenshot
4. Use screenshot tools to capture 1280x800 images

### Method 3: Using Browser Developer Tools
1. Open Chrome Developer Tools (F12)
2. Click device toolbar icon
3. Set custom device to 1280x800
4. Navigate to extension
5. Take screenshots using browser's capture tool

## Screenshot Naming Convention
- `screenshot-1.png` - Main interface
- `screenshot-2.png` - Search and filter
- `screenshot-3.png` - Session management
- `screenshot-4.png` - Bulk operations
- `screenshot-5.png` - Settings and options

## Tips for Good Screenshots
- Use realistic tab titles and URLs
- Show meaningful tab counts (not just 1-2 tabs)
- Include variety in domain names
- Show both active and inactive tabs
- Include some selected tabs to show selection functionality
- Use clear, readable text
- Avoid cluttered or confusing layouts
- Show the extension's value proposition clearly
